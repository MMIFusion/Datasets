Built for researchers.
Made better, together.

本文汇总图像融合及相关多模态感知数据集，先按模态与融合类型分类，再按具体任务整理。部分数据集同时适用于多项任务，按主要用途归类，具体适用范围以原论文和数据集说明为准。分享顺序以整理时间为主，与排名无关。

汐萌 · 整理寄语

本文80%的数据集是平时阅读论文收集整理而来，余下工作用AI查漏补缺，并补充部分信息。可能会存在一定的不足或错误，还请见谅。因此，一切信息请参考并以原文为主！希望总结的内容，能对你的研究有所帮助。最后，感谢全部开源的研究者，为信息融合完善数据基石。

囗〇 · 给研究者的话

希望这篇文章能让你少花一些找数据的时间，多留一点精力给真正想解决的问题。选数据前，先看它是否贴近您的任务，再核对配准、标注、训练测试划分与使用许可。遇到不一致的信息，请回到原论文和官方仓库，也欢迎把勘误与新资源分享出来。愿您的每一次实验，都离清楚、可靠的结论更近一步。
